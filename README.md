# 小觅法务官网 · mijing-web

小觅法务（https://mjvia.com）官方网站源码。

小觅法务是面向中小企业的企业法务 AI，由天津觅径科技有限公司运营，提供合同审查、用工预检与企业知识管理服务。纷繁之中，自有明径。

- 官网：https://mjvia.com
- 场景指南：https://mjvia.com/guide
- 小觅月报：https://mjvia.com/monthly/2026-11
- 合同管理调研：https://mjvia.com/survey/contract-management-2026

## 技术栈

- React 19 + vinext
- Cloudflare Workers

## 构建

```bash
npm install
npm run build
```

部署配置见 `ops/`。
